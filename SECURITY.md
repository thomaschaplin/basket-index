# Security policy

Basket Index handles people's shopping history, so privacy bugs count as security bugs. That includes anything that could send receipt data off the device, weaken the Content-Security-Policy, or make the downloader scripts do more than the README says.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private vulnerability reporting instead: the **Security** tab of this repository, then **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You should hear back within a week.

## Supported versions

Only the latest version on `main` (the one deployed at basketindex.thomaschaplin.me) gets fixes.
